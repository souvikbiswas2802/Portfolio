> A sleek, responsive, and animated personal portfolio built using **HTML**, **CSS**, and **JavaScript**, with a custom **gooey cursor**, **smooth scrolling**, and **dark/light mode toggle**.  

---

## ✨ Features  

🌀 **Gooey Cursor Animation** – Follows your mouse dynamically with a trailing dot effect.  
🌗 **Dark & Light Theme Toggle** – Persistent across sessions using `localStorage`.  
🎞️ **Smooth Scroll Navigation** – Scrolls seamlessly to different sections.  
💫 **Card & Section Animations** – Elements fade and slide into view on scroll.  
🧠 **Responsive Design** – Works perfectly on all devices.  
⚡ **Optimized Performance** – Lightweight and smooth at 60fps.  

---

## 🧩 Tech Stack  

| Technology | Purpose |
|-------------|----------|
| 🧱 **HTML5** | Structure of the site |
| 🎨 **CSS3 (Flexbox, Grid, Animations)** | Styling & layout |
| ⚙️ **JavaScript (ES6)** | Logic, effects, and interactivity |
| ☀️ **LocalStorage API** | Theme persistence |
| 💻 **Intersection Observer API** | Smooth section reveal animations |

## 🚀 Getting Started  

### 🔧 Installation  

1. **Clone the repository**
   ```bash
   git clone https://github.com/souvikbiswas2802/Portfolio.git
   cd Portfolio
   ```

2. **Open the project**

   ```bash
   open index.html
   ```

   or simply drag it into your browser!
